# 🌿 Git Branch Map

A lightweight Python CLI tool that displays Git branches and highlights the currently active branch.

## Features

- List Git branches
- Detect the current branch
- Clean terminal output
- Uses Git directly
- No external Python packages

## Requirements

- Python 3
- Git

## Run

Clone or place the project inside a Git repository, then run:

```bash
python main.py
```

## Example

```text
🌿 Git Branch Map
===================================

👉 main
   feature-login
   development
```

## Built With

- Python
- Git
- subprocess
